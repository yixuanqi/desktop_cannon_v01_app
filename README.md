# Desktop Cannon · 桌面小炮

一个可以在 Windows 桌面角落拖动、蓄力并向桌面发射炮弹的小玩具。开启可选的桌面图标物理互动后，炮弹可以让**图标视觉副本**飞散、旋转、落地并回到原位，真实 Explorer 图标和文件**不会被移动、删除或改写**。

## 30 秒上手

1. 运行 Windows 安装版，或解压绿色版后启动 `DesktopCannon.exe`。
2. 拖动小炮炮身改变位置；**向右拉红色炮闩**蓄力，上下拖动微调炮口角度，松手发射。聚焦炮闩后也可以按 Enter/空格发射，方向键调整角度。
3. 首次启动会显示引导卡。图标飞散**默认关闭**，点“开启图标飞散”或右击系统托盘开启。也可使用炮身旁的小按钮快速开关。

小炮会记住位置、音效和明确选择过的图标互动开关。隐藏小炮时暂停桌面扫描与视觉遮罩，重新显示后按保存的偏好恢复；托盘中可以重置小炮位置、关闭音效或退出。

## 新增：30 秒虚拟桌面靶场（v0.7.0）

在小炮右上角点击 **「🎯 30 秒靶场」** 即可启动（再次点击退出），屏幕上出现最多三个手绘练习靶。目标位置取自当前炮口的真实物理弹道。击中练习靶获得 100 分起的连击奖励，成绩与本地最佳成绩会显示在左上角的小卡片里。

靶场是独立的**虚拟目标模式**，不依赖 Explorer 图标、壁纸采样，也**不会自行开启**真实图标物理互动。它不是给真实文件或快捷方式记分；启动靶场后图标互动原有功能仍按用户独立设置运行。暂停/隐藏应用、改变分辨率或结束 30 秒会结束当轮挑战。

## 能做什么

- 17 帧小炮俯仰素材；拖动炮闩蓄力，轨迹预览与真实炮弹采用同一固定步长物理模拟。
- 炮弹可在桌面空间运动、反弹、播放音效与粒子特效。
- 对**已通过安全校验**的 Windows 桌面图标，生成多对象飞散、碰撞、落地和弹性回位效果，最多同时 12 个视觉副本。
- 图标采集在命中前预热。无法安全提取图像或还原壁纸时仅显示火星，不显示错误的半截图标。
- 新增首次启动引导、图标互动开关、分类型错误提示、用户偏好持久化和回归测试。

## 兼容范围与隐私

- **仅 Windows x64**，支持 Windows 10/11 的桌面使用场景；绿色版需要系统具备 Microsoft Edge WebView2 Runtime。安装版由 Tauri/NSIS 构建。
- 桌面图标视觉飞散目前主要针对**主显示器**，静态壁纸的**填充 / 拉伸**模式；动态壁纸、多显示器复杂布局或无法恢复背景的图标会安全降级。
- 首次使用图标互动须明确开启；状态可关闭。采集图标的视觉像素和背景图只在本机内存中处理，不调用云服务，不写入文件或上传截图。
- 文件和 Explorer 图标位置不会被改变。图标碰撞检测用 Shell 报告的近似区域，不能理解为像素级精确命中。
- 位置、音效、授权开关和引导是否完成，保存在系统应用配置目录的 `settings.json`。

如果绿色版启动后完全无窗口，请先确认 WebView2 Runtime 已安装，再检查系统托盘。部分 Windows 安全机制可能提示未签名的应用；应自行核对 GitHub 来源与发布包，不建议随意忽略安全警告。

## 参赛与真实 Windows 验收

**自动化构建成功不等于所有 Windows 桌面场景都已通过。** 自测分为：

- `npm test`：纯 JS 算法、设置和集成约束。
- `npm run test:ui`：Chromium 浏览器预览真实鼠标拖动、蓄力、瞄准、键盘发射、粒子动画。
- `cargo test --manifest-path src-tauri/Cargo.toml`：原生设置序列化和屏幕恢复安全判断。
- Windows CI：以上测试、网格素材验证、安装版和绿色版生成。
- 真正的 Explorer 前景判定、图标视觉遮罩、125%/150% DPI、壁纸切换、干净 Windows 安装：需要按 [Windows 实机验收表](docs/WINDOWS_ACCEPTANCE.md) 操作，未测试的项目不能标记通过。

参赛演示拍摄建议见 [60 秒演示脚本](docs/DEMO_SHOTLIST.md)。仅展示真实拍到的运行效果，浏览器预览须明确标明“模拟”。

## 开发与构建

```powershell
npm ci
npm test
python -m pip install numpy pillow playwright
python -m playwright install chromium
npm run test:ui
python scripts/validate_mesh.py
cargo test --manifest-path src-tauri/Cargo.toml
npm run build
```

版本以 `package.json` 为准；`scripts/sync-version.mjs` 检查 Cargo、Tauri 版本并生成浏览器版本标识。CI 只在完整测试及 Windows 编译通过后发布对应 Tag/Release。
