# V0.1.1 - 炮闩适配与炮身拖动

## 问题一：炮闩拉动时脱节、不协调

根因：红色拉柄原本被渲染为 63×39 CSS px，放大/拉伸了主体美术；拖动时只移动拉柄，连接杆不随之伸长。另外发射后坐动画仅移动炮身，不移动拉柄。

处理：
- 视觉资源恢复约 45×23 px 的正确长宽比，外面保留 65×40 px 的鼠标命中区域。
- 在炮尾增加 `#bolt-spring`，固定左端，宽度随拉动距离增长。
- 新建 `#rig` 包裹炮身、弹簧和拉柄；待机与后坐对整套结构一致运动。
- `MAX_PULL_PX=90`，最大拉动时拉柄右边界约 327 px，保留 33 px 防裁切缓冲。

## 问题二：鼠标左键拖不动炮身

处理：
- 炮身/木轮：按下鼠标左键移动整个交互窗口（Tauri `startDragging`；浏览器预览移动 iframe）。
- 红色拉柄：保留独立 PointerCapture 蓄力动作；不会触发窗口拖动。
- Tauri 只对 `cannon` 交互窗授予 `core:window:allow-start-dragging`，overlay 继续鼠标穿透。
- Rust `get_layout` 每次读取原生炮窗和覆盖层最新 physical position；前端每次发射前重新取坐标，避免移动后从旧位置发射。

## Windows 用户如何复测

1. 解压覆盖旧版源码（或者用本包作为新工程）；关闭旧版小炮进程。
2. `npm install`，运行 `npm test`，再执行 `Windows开发启动.bat` 或 `npm run dev`。
3. 左键按住炮身/轮子移动位置；按红色球柄向右拖 30/60/90 px，确认弹簧同步伸长并复位。
4. 把小炮移到屏幕左上，再蓄力发射，确认炮弹从**新位置**产生。
5. 在 100%、125%、150% 缩放下重复，观察局部透明交互窗是否拦截其他桌面点击。
