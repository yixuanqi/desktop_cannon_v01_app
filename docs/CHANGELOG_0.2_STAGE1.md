# 桌面小炮 V0.2-A：无损分层 / 草地静止

## 完成内容

- **唯一金标**：`web/assets/cannon_base.png`（V0.1.1 经过实际运行的资源）。没有使用后来重新生成的炮车设计来替换它。
- 原图透明图层拆分：`ground.png`（地面花草）、`barrel.png`（炮管/绿芽）、`chassis.png`（兔子木轮/底座）。所有文件均为 **480×350 RGBA 真透明 PNG**，坐标一致。
- 保留已有 `part_bolt_knob.png` / `part_spring.png` 等炮闩素材与交互，不重画拉柄。
- CSS 中的摇摆与后坐只作用于 `#barrel-pivot`。地面和木轮在开炮动画中不再跟随旋转。
- `web/assets/layers/manifest.json` 给 Agent 记录了各层顺序、零姿态尺寸、摆放位置、候选转轴。
- 新增测试和可重建素材的脚本。

## 已完成验证

1. 静态合成 RGBA 与 V0.1.1 原图，在所有非透明像素 **逐像素相同**；所有像素的 Alpha 通道相同。
2. 浏览器绘制尺寸 214×156，模拟双线性采样分别缩放并叠加后的平均 RGB 误差：浅色背景约 **0.074/255**，深色背景约 **0.058/255**。这个数值反映数值逼近，不等价于在 WebView2 上的视觉验收。
3. 原有拖动/蓄力/物理/事件测试和新增分层结构测试通过。
4. 当前容器无 Windows Rust/WebView2 环境，**未执行 Windows 实机验收**；Chromium 自动化导航被系统管理员策略 `ERR_BLOCKED_BY_ADMINISTRATOR` 拒绝。

## 不在本阶段：请不要当作已经完成

- 二维炮闩输入、可变发射角及预测弹道。
- 中/大幅度旋转后的遮挡补绘；这是当前素材的下阶段必做门槛，不能直接旋转 ±15° 就发布。
- Windows 桌面用户实机回归。
