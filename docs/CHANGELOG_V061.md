# V0.6.1 变更记录

## 修复

- 将图标屏幕采样、静态壁纸解码、像素差分、PNG 编码和 WebView 图片解码全部移到功能开启后的预热阶段。
- 命中回调改为同步缓存查找，命中后同一渲染帧创建图标刚体状态，不再异步补播。
- 用炮弹命中速度产生初始冲量；用碰撞点偏心量计算角速度。
- 新增 1/120 秒固定步长累加器，保证 60/75/144Hz 下物理轨迹一致；加入重力、阻尼、屏幕边界反弹和阻尼弹簧回位。
- 图标位置或缓存不一致、素材未预热、桌面安全条件失效时立即降级，不延迟启动。

## 菜单整理

托盘现在只保留：显示/隐藏小炮、音效开/关、桌面图标物理互动、退出。

已删除独立的图标命中开关、检测框调试开关、独立诊断窗口和对应正式运行代码。命中检测被合并到唯一的桌面图标物理互动开关中。

## 保留约束

- 不移动、不重排、不删除真实 Windows 桌面图标或文件。
- 仅主显示器、静态壁纸 Stretch/Fill 模式尝试视觉遮罩。
- 多图标之间的刚体碰撞/连锁打散暂未实现。
- Windows 原生编译和真实 WebView2 效果必须在 Windows 实机验收。
