# 参赛视频脚本（真实 Windows 录制，约 60 秒）

| 时间 | 镜头 | 可核验重点 |
|---|---|---|
| 0–8s | 真实 Windows 桌面，显示小炮并拖到角落 | 小炮不会被前景窗口裁切 |
| 8–18s | 新用户首次引导和“开启图标飞散”按钮 | 明确授权，实用性 |
| 18–30s | 拉红色炮闩、微调仰角、松手发射，显示预测轨迹 | 操控与弹道 |
| 30–48s | 炮弹命中多个**真实 Explorer 图标**，图标飞散落地回位 | 产品最大亮点 |
| 48–55s | 切换开关、重新放置大炮、音效或托盘操作 | 可控、安全、可用 |
| 55–60s | 项目名称与 Releases 地址 | 安装包可下载 |

**拍摄约束**

- 使用 Windows 实机屏幕录制，不使用网页合成 GIF 冒充真实桌面互动；如果要放浏览器预览，明显标“浏览器模拟”。
- 桌面用临时普通快捷方式和无隐私数据的假文件，避免在公开参赛作品里泄露真实路径、姓名和账号。
- 在受支持的静态壁纸模式下展示，别在未支持的动态壁纸环境中强行伪造飞散。
- 遇到失败镜头应先定位并真实重测，而不是剪辑掉所有失败并宣称兼容全部环境。
- TRAE 开发证据应附真实 Session ID、开发截图与 commits，不得编造会话或测试记录。
