# Desktop Cannon V0.6.1 — 单图标物理飞散与自动回位

> 当前版本把 V0.6 的“命中后临时截图/提取/解码”改成**启用功能时预热素材、命中时同步启动物理模拟**。单图标视觉飞散仍是 Windows 实验功能；不移动 Explorer 的真实图标位置，不操作文件。

## 本版修复目标

1. **消除命中延迟**：用户打开托盘的「桌面图标物理互动」后，后台一次性读取当前桌面图标候选、批量采样静态壁纸背景和图标单元、在 WebView 中预解码。炮弹命中时只做缓存查找和状态初始化；不再调用 Windows 截图、壁纸解码、PNG 编码或图片解码。
2. **改为真实二维动力学**：命中瞬间把炮弹当前速度按冲量系数传给图标副本；根据偏心碰撞点计算角速度；按固定 1/120 s 步长积分重力、阻尼、屏幕边界反弹和角运动；飞行阶段结束后用阻尼弹簧将图标拉回原位。
3. **简化托盘**：普通用户只看到一个「桌面图标物理互动」开关。旧的「图标命中实验」「显示图标检测框」「独立诊断窗口」已从托盘和正式运行路径移除。命中检测、调试状态与素材预热由一个开关内部统一管理。

## 物理模型

单位为 CSS px、秒。实现位于 `web/js/icon-interaction/illusion.mjs`。

### 初始冲量

炮弹撞击时将当前速度传给图标：

\[
\mathbf v_0=\operatorname{clamp}(k_i\mathbf v_{projectile},v_{max})
\]

默认 `impulseScale=0.32`、`maxLaunchSpeed=620 px/s`。方向与炮弹一致，力度随炮弹速度变化。

### 偏心碰撞产生旋转

以图标中心为原点，碰撞点偏移为 \(\mathbf r\)，冲量速度为 \(\mathbf v_0\)：

\[
\omega_0=\operatorname{clamp}\left(\frac{r_xv_y-r_yv_x}{I}\,k_\omega,\pm\omega_{max}\right)
\]

其中矩形近似转动惯量 \(I=(w^2+h^2)/12\)。因此击中中心附近旋转较小，擦中边角时会产生明显翻转。

### 飞行、重力与碰撞

固定步长 `1/120 s`：

\[
\dot x=v_x,\quad \dot y=v_y,\quad \dot v_y=g
\]

图标与主显示器的左右/上边界及任务栏上沿发生碰撞，按恢复系数损失能量；角速度同步阻尼。飞行阶段约 0.92 s。

### 弹簧回位

飞行阶段后进入回位阶段：

\[
\mathbf a=-k_s(\mathbf x-\mathbf x_0)-c_s\mathbf v
\]

旋转角也采用阻尼弹簧回正。达到位置、线速度、角度和角速度阈值后清除副本与遮罩，Explorer 原图标自然重新显现；最长动画 3.8 s。

> 当前是**单图标刚体近似**，尚未实现多个图标之间的互相碰撞、连锁冲量或多物体堆叠。不会把缓动曲线冒充物理模拟。

## 命中前预热流程

```text
托盘打开「桌面图标物理互动」
  -> Shell 只读枚举图标单元
  -> Rust STA 线程只加载一次壁纸
  -> 批量抓取各候选单元的屏幕像素
  -> 与壁纸裁剪块做边缘一致性检查
  -> 提取透明图标副本 + 背景遮罩
  -> IPC 一次性返回批次
  -> WebView 预解码全部 PNG 并建立内存缓存
  -> 显示“素材已预热”
  -> 炮弹命中：同步 cache lookup + 创建刚体状态
  -> Canvas 同帧绘制遮罩和运动副本
```

任何候选单元未通过壁纸匹配、位置过期、素材未预热或当前应用不满足安全条件时，都只显示命中火星，不延迟补播动画。

## 托盘菜单

正式菜单仅保留：

1. 显示 / 隐藏小炮
2. 音效开 / 关
3. 桌面图标物理互动：开启（默认关闭）/ 关闭桌面图标物理互动
4. 退出桌面小炮

旧菜单项处理：

- 「图标命中实验」：合并进唯一的物理互动开关，作为内部步骤，不再单独暴露。
- 「显示图标检测框（调试）」：从用户菜单和运行 UI 删除；候选坐标仍用于内部碰撞。
- 「V0.6 · 打开独立诊断窗口」：删除独立 WebView、命令和菜单项。自动化测试与 Windows 验收脚本承担开发验证。

## 安全边界

- 只读 `IFolderView::GetItemPosition`；不调用 `SelectAndPositionItems`、`SetItemPosition`、ListView 移动消息。
- 不移动、不重排、不删除 Explorer 图标和真实文件。
- 只支持主显示器、静态壁纸 Stretch/Fill 模式；其他模式或壁纸不匹配时拒绝飞散。
- 全屏 overlay 保持鼠标穿透；鼠标进入被遮罩的真实图标区域、前台应用不再满足桌面安全条件时，立即取消动画。
- 图标素材和壁纸裁剪仅在内存中短暂存在，不写入磁盘。
- 关闭功能、隐藏小炮、页面卸载、分辨率变化或实验失败时，立即清除活动副本和缓存。

## Windows 实机验收

1. 关闭所有旧进程，运行 `Windows验证V06.bat`。
2. 启动 `Windows开发启动.bat`，右键托盘，只应看到一个「桌面图标物理互动」功能开关。
3. 开启后等待提示「图标素材已预热：N 个」。预热阶段可能耗时，但炮弹命中时不得再出现采样延迟。
4. 对准一个普通快捷方式发射：图标应在碰撞的同一帧开始沿炮弹方向运动，受重力影响下落/反弹，偏心命中应产生旋转，随后弹簧回位。
5. 连续测试不同蓄力、不同命中点；力度越大初始位移速度越高，擦边命中旋转更明显。
6. 如果素材未通过匹配或位置过期，必须立即降级为火星，不允许炮弹飞走后再补播图标动画。
7. 关闭开关，确认所有遮罩/副本立即消失，真实桌面图标仍在原位且可以正常点击。
