# Desktop Cannon v0.7.0 · 可选 30 秒虚拟桌面靶场

## 定位与安全边界

靶场是可选、可关闭的**手绘虚拟目标小游戏**，与 Windows Explorer 图标物理互动相互独立。它不调用 Shell、壁纸截屏、真实图标位置改变或文件操作，也不把普通 Shell 碰撞候选当作得分。

- 默认自由发射；点击炮身右上「🎯 30 秒靶场」启动，点击相同按钮可退出。
- 仅当**炮弹实际物理运动轨迹**扫过一个仍存在的虚拟靶时计分；同一目标不能重复得分。
- 每次靶场在支持的布局上生成最多三个沿真实发射轨迹可达的目标；全部命中后自动刷新下一组，直到 30 秒结束。
- 单靶基础 100 分，4 秒以内连续命中连击递增 50 分，连击最多 ×5 阶段。
- 最佳成绩只写入本机 WebView 的 localStorage（键 `desktop-cannon.range.best.v1`），不上传或共享。
- 隐藏窗口、屏幕显示尺寸变化、手动退出均结束当轮靶场；没有背景定时持续扫描桌面。
- 如果当前炮身太靠左或者屏幕空间不足以布靶，会提示把炮身移到主显示器右侧，**不会凭空生成不可到达的目标**。

## 实现说明

`web/js/range-mode.mjs` 只包含纯物理布靶与扫掠圆碰撞判定，使用 `stepProjectile()` 同一 1/120 秒物理步长。不能靠随机数编造命中或越过屏幕边界。实际炮弹通过 `overlay.mjs` 的 `advanceProjectileFrame` 提供真实 `onSegment`，靶场只观察该回调，不更改炮弹轨迹、速度或 Explorer 状态。

`web/js/range-draw.mjs` 在已有透明 Overlay canvas 上绘制图形和左上角得分卡，overlay 仍保留 Windows 鼠标穿透；操控按钮放在已有 360×240 炮身交互窗内，既不扩大穿透层也不创建新顶层窗口。

## 验收与限制

自动化：
- Node 回归：目标生成的位置、真实模拟可达性、穿透/擦边命中、单次记分、连击、倒计时、异常小屏降级；
- Chromium：点击启动与关闭虚拟靶场、看到虚拟靶、浏览器预览中保持真实图标物理捕获关闭、恢复原始自由发射；
- Windows CI：上述测试连同 Rust、素材、Tauri 原生打包验证。

真实 Windows 桌面：运行 v0.7.0 后手动检查靶场按钮不遮挡炮闩、开关功能、前景窗口的视觉位置、主屏 DPI 调整、托盘隐藏再显示；靶场模式不能绕过 v0.6.8 对真实图标互动的安全门控。若尚未执行现场验收，不能标记为已实机通过。

## 非目标

本版不增加商城、金币经济、联机、复杂炮弹、账号或虚假的“击飞真实图标得分”动画。靶场主要承担首玩引导和持续可玩性的轻量增强。
