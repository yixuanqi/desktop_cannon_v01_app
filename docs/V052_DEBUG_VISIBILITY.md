# V0.5.2 桌面图标调试框可见性修复

## 用户报告

V0.5.1 实机截图没有左上角状态和绿色图标框。仅凭截图无法断言是开关未开启、事件丢失、Shell 返回为空或坐标过滤。旧版前端依赖托盘事件触发调试状态，Rust 没有提供调试开关的读回字段；调试文字绘制于 Canvas，缺少与动画循环解耦的稳定 HUD。

## 已修复

1. `icon_capabilities()` 新增 `debug` 属性；Rust 菜单事件发送确定的布尔值 `icon:debug-changed`，不再仅仅让前端盲目取反。
2. Overlay 页面启动时和每 1.5s 从 Rust 读取开关实际状态进行纠偏。即使消息在前端 listener 建立前发出，HUD 也会在下一次同步后出现。
3. 将诊断文字移到固定 HTML 浮层 `#icon-diagnostic`，不再依赖 Canvas 物理帧或命中动画。绿色候选框仍在 Canvas 绘制。
4. 不开启图标命中实验时，只要开启调试，也明确显示“未开启图标命中”；Shell 错误、无图标、坐标过滤均有不同文本。
5. V0.4 炮体、网格微动及炮弹物理完全不变。只读 Shell，未实现飞散与遮挡。

## Windows 验证步骤

1. **结束旧版程序**（包括托盘），解压完整 V0.5.2 工程，运行 `Windows开发启动.bat`。
2. 在托盘菜单中点击 `显示图标检测框（调试）`。**即使还没有开启图标命中实验，屏幕左上角也应在约 2 秒内出现深色诊断浮层，写着“未开启图标命中”。**
3. 再点击 `图标命中实验：开启（默认关闭）`。左上角应变成 `读取图标中…`、`图标候选就绪` 或明确错误；若有候选，再显示绿色框。
4. 如果浮层仍不出现：确认已关闭旧版；尝试关闭并重新启动程序，并检查托盘菜单是否从 `显示图标检测框` 变为 `隐藏图标检测框`。提供此菜单截图和控制台错误。
5. 不要求炮弹图标飞散；V0.5.2 仍是命中 POC。
