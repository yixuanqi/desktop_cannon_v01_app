## V0.5.1 实机诊断优先顺序

请先运行新版，右键系统托盘图标打开 **图标命中实验**，再打开 **显示图标检测框**。左上角应该始终显示 `V0.5.1` 状态。

1. **未开启图标命中**：先开启实验开关。
2. **Windows Shell 读取错误 / probe-error**：拍下错误码和本机 Windows 版本；不要继续尝试飞散。
3. **前台非桌面/小炮：安全过滤**：切回桌面或在小炮窗口里拉闩，然后观察是否变成 `ready`。
4. **Shell 未返回图标**：Explorer 的 `IFolderView` 没返回候选；需调查 COM 枚举。
5. **图标坐标未通过转换**：可能是多显示器或 DPI 原点错误，截图绿色框进行校准。
6. **图标候选就绪**：原始数 / 候选数应大于 0，绿色框覆盖图标格；发射炮弹穿过绿色框，应看到 `命中` 数增长，并产生额外火星。

注意：普通发射声音不是图标命中声音。V0.5.1 不会移动任何桌面图标，也没有视觉飞散；只是 M1-M2 的读数据/碰撞诊断版本。Windows 原生构建和遮挡仍待实测。

# V0.5 Windows 实机验收操作单（M1/M2/M3）

## 入口

1. 在 Windows 11 开发机解压，关闭 V0.4.1 旧进程，双击 `Windows验证V05.bat`。若原生构建失败，记录完整 `cargo check` 输出，不代表功能已验收。
2. 运行 `Windows开发启动.bat`，在托盘打开 **图标命中实验**，然后点击 **显示图标检测框（调试）**。
3. 点击空白桌面确保 Explorer 的桌面处于前台。应能看到绿色候选网格；未显示则检查 Shell 视图接口、前台识别、DPI 坐标换算。
4. 拿 10 个分布在桌面左、中、右的图标（文件、文件夹、快捷方式、不同长度标签）与候选网格逐一比对，保存未经裁剪的 Windows 截图。网格尺寸是近似值，不能冒充实际图标边框。
5. 炮弹实际发射穿过候选网格时应出现额外的轻微火星，不应生成图标副本。测试高速/低速/边缘擦过及连续命中。原始位置必须完全不变。
6. 打开浏览器覆盖部分桌面图标，确认系统保守禁止该情形的图标命中实验；如无法判断，则立即关闭实验开关。
7. 关闭实验开关并验证没有新的 Shell 轮询、绿色框和图标反馈，原有炮弹正常飞行。

## 故障注入

- 改变 DPI 为 125%/150%、分辨率、移动图标、重启 Explorer：期望刷新或自动降级，不得沿用旧网格；失败处记录 `explorerEpoch` 和截图（不要记录用户真实路径）。
- 手动隐藏小炮、退出进程：绿色框立即清除，鼠标点击仍然穿透 overlay。
- 功能默认关闭，文件、快捷方式、真实图标位置不改变。

## 重要 M3 停止条件

当前工程 **没有实现原位遮罩**，M3 未通过，飞散/回位尚未开发。不能将绿色框/火星的成功称为“图标飞散成功”。

要继续进入 M4，需先完成原图标 + 文字标签的无残影遮罩，并对复杂文字壁纸、普通应用窗口覆盖、100%/150% 缩放录屏检查，详见 `DESKTOP_ICON_INTERACTION_V05.md`。
