## 未能在当前环境验证

当前工作容器没有 Rust/Cargo/MSVC Windows 构建工具，因此未运行 `cargo check`，也未生成 Windows 安装包。Windows C++/COM/GDI 原生代码和 WebView2 双窗口效果需要用户在 Windows 机器上运行 `Windows验证V06.bat` 验证。

## Windows 实机验收重点

1. 托盘只出现一个「桌面图标物理互动」开关。
2. 开启后先显示预热提示；预热完成后才开始有图标飞散能力。
3. 命中时图标应在碰撞同帧启动，不允许炮弹离开后延迟补播。
4. 初始运动方向应与炮弹方向一致；力度影响初速度；重力使图标下落；偏心命中产生旋转；触边/触底发生能量损失反弹；之后弹簧回位。
5. 遮罩失败时只显示火星；关闭开关后副本和缓存立即清除。
6. Explorer 真实图标位置与文件始终不变。
