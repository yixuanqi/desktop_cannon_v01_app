# V0.4 小角度网格变形 — 验证记录

## 已验证

- `python scripts/generate_mesh_frames.py`：生成 17 张 480×350 RGBA 透明 PNG，间隔 0.5°。
- `python scripts/validate_mesh.py`：17 张尺寸/Alpha 一致，34° 与原版 **所有 RGBA 通道逐像素一致**，30° 和 38° 非相同图片，草地底部变化受限。
- `node --test tests/*.test.mjs`（23/23 通过）：二维拉闩、角度量化、炮口动态定位、放手发射、Esc 取消、移动后发射、物理边界和预测轨迹一致性。
- 离线预览 `docs/v04_mesh_interaction_preview.png`：使用原版图派生帧 + 原有红球/弹簧 PNG 合成三姿态。
- 预览服务器 `http://127.0.0.1:1420/preview.html` 与 `/assets/mesh/frames/pitch_08.png` 返回 HTTP 200。

## 未验证 / 风险

- Windows 原生 Tauri EXE 未在本环境编译（缺 Windows/Rust MSVC 工具链）。
- 真实 Windows WebView2、显示缩放、置顶、任务栏和鼠标穿透未实机验收。
- Chromium 截图在当前环境未成功；离线合成不等于 UI 实机截图。
- 30°/38° 仍存在小幅非刚性变形；在高分辨率屏幕要检查边缘/叶片/木轮形变。
- 17 帧预加载的解码内存和 WebView2 进程占用尚未进行 Windows Release 实测。

## Windows 实机检查清单

- [ ] 30°、34°、38° 连续拉动时视觉平滑，没有闪白、变黑、空白帧。
- [ ] 黑/白背景下炮管、草地边缘没有新毛刺和剪切缝。
- [ ] 红色拉柄与炮尾保持连接，拉到最大力度不会被窗口裁掉。
- [ ] 草地和兔子木轮形变微小，不随炮管整体移动。
- [ ] 预测弹道起点与炮口吻合，三档角度实发方向匹配。
- [ ] 按住炮身可移动窗口，鼠标拉闩不移动窗口。
- [ ] 同时打开浏览器、资源管理器，炮弹真正跨窗口飞行且鼠标可穿透。
- [ ] 静置 5 分钟记录 CPU/GPU/内存，连续发射 1 分钟记录峰值。
