# Windows 实机验收单 — Desktop Cannon v0.6.8

> 此文档是**需要执行的清单**，不是声称已通过。浏览器 CI 无法代替 Windows Explorer 真实桌面验证。

## 自动化前置

- GitHub Actions：Node 全量测试、浏览器拖动/蓄力/发射、素材校验、Rust 单测、NSIS/便携包构建均为 green。
- 新版安装包与绿色版必须来自同一次 `main` 提交，版本号在应用配置与 Release 一致。
- 在一台未安装过 Desktop Cannon 的 Windows x64 电脑/虚拟机、另在开发机测试；绿色版注意 WebView2 Runtime 是否存在。
- 执行 `powershell -ExecutionPolicy Bypass -File scripts/windows-clean-smoke.ps1 -ExePath '...\DesktopCannon.exe'` 收集哈希、Runtime 检查及进程启动状态。安装版则先运行安装程序，再用实际安装 EXE 执行脚本。脚本不会关闭程序，也不能代替人工视觉检查。

## 验收表（每项填“通过 / 失败 / 不适用”，保留屏幕录制）

| 编号 | 场景 | 预期 |
|---|---|---|
| W01 | 全新设置目录首次启动 | 出现简洁引导；图标互动默认关闭；可拖炮身并发射 |
| W02 | 点击“开启图标飞散” | 明确授权生效；托盘和快捷开关同步；状态提示清晰 |
| W03 | 关闭/开启、托盘隐藏/恢复 | 不存在残影或透明遮挡；可继续拖动与发射 |
| W04 | 拖炮身到左下角并停留 10 秒 | 不被 2 秒环境轮询推回工作区 |
| W05 | 退出并重启 | 恢复上次炮身位置及音效，图标开关按明确保存选择恢复 |
| W06 | 从托盘重置炮身位置 | 恢复主屏幕右下角，仍可拖动 |
| W07 | 125%、150% DPI 与分辨率变化 | 炮身尺寸及图标坐标一致，不裁切、不回弹 |
| W08 | 实拍桌面常见快捷方式、文件夹、多行文字 | 预热成功的图标完整飞散；真实文件及 Explorer 位置不变 |
| W09 | 静态填充/拉伸壁纸 | 背景无明显残影；物理回位正确 |
| W10 | 不支持的壁纸模式/动态壁纸 | 清晰显示不支持原因，普通炮弹仍可用，不能出现破碎图标 |
| W11 | Explorer 重启、图标移动、壁纸切换 | 旧缓存自动失效，不播放陈旧遮罩 |
| W12 | TRAE/浏览器前台与切换最小化 | 不误遮挡前景应用，不偷焦点，小炮保持完整 |
| W13 | 桌面前景下连续发射 1 分钟 | 无崩溃、卡顿、重复图标失控或无限增长缓存 |
| W14 | 退出软件 | 不残留进程或透明遮罩，文件与桌面图标位置未改变 |
| W15 | 无 WebView2 的干净 Windows 环境 | 安装版能正确引导/报告依赖；便携版 README 明确依赖 |
| W16 | 全新用户、不看 README | 30 秒内理解“拖动、拉闩、开启图标互动”三种操作 |

## 状态边界

本仓库自动化可以验证代码逻辑和 Windows 原生编译。真正的干净机器状态、UAC/SmartScreen 体验、Explorer 图标渲染和实拍视频必须在有交互桌面权限的 Windows 上验证。
