# V0.5.1 Windows 桌面图标命中诊断修复

## 用户反馈

炮弹有音效、可以穿过图标区域，但是没有图标互动。这不是图标已经飞散失败——V0.5 原本未实现飞散，且连命中火星的实验检测也可能被错误过滤。

## 根因与修复

1. **旧版前台判断误杀**：`desktop_icon_probe.cpp` 的 `dc_desktop_foreground()` 只把 `Progman/WorkerW` 当成桌面。点击炮闩后小炮窗口可能是前台，点击托盘后 taskbar 可能是前台，导致所有图标候选被 `desktopForeground=false` 拦掉。现在允许程序自身的前台窗口和 Explorer 任务栏窗口，同时继续对不相关前台窗口保守过滤。
2. **失败静默**：`runtime.mjs` 捕获 Shell 错误后清空候选不报告；调试开关若未启用实验也无显示。现在显示禁用、探测失败、前台过滤、空图标、坐标无效、就绪等状态，包含原始计数、候选数、命中数和错误信息。
3. **初始状态竞争**：overlay 先注册了事件但可能错过托盘状态事件；现在启动时调用 `icon_capabilities` 同步开关，并在获取布局后尝试刷新。

## 立即验证

1. 关闭所有旧版进程，再从本包 `Windows开发启动.bat` 启动（旧版不能热更新代码）。
2. 托盘依次点 `图标命中实验：开启`、`显示图标检测框（调试）`。
3. 屏幕左上角应显示状态；若候选就绪应有绿色单元框，原始数/候选数均大于 0。
4. **只在绿色框经过炮弹时**检查“命中”计数增长与额外火花。发射音效只是炮弹本身发出的，不能作为命中证据。
5. 记录左上角文字，尤其 `probe-error` 的 HRESULT / `foreground-filtered` / `coordinate-filtered`。提供屏幕截图用于下一轮精确图标边界校准。

## 不能宣称已实现

- 调试框是 Shell 图标单元的**近似矩形**，不是图像+标签的真实边界。
- 本版不截屏、不读取桌面文件内容、不移动文件/快捷方式。
- **没有图标消失、飞散和自动回位**。该功能仍需 M3 Windows 真机遮罩可行性验证，不能用重复显示两个图标冒充。
- 此环境仅能运行 Node/静态检查，不能构建或验收 Win11 Explorer/COM 原生模块。
- 当前“前台安全过滤”仍是全局判断；未来应升级到每图标的真实可见性/遮挡测试，避免应用窗口遮住部分图标时误报。
